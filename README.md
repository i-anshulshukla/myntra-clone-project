# Myntra Frontend Clone 🛍️

A pixel-perfect front-end clone of the **Myntra** e-commerce platform built using **pure HTML5 and CSS3**. This project replicates the core design, user interface layout, navigation structure, and visual aesthetic of Myntra's web interface.

---

## 🌟 Key Features

- **Header & Navigation**:
  - Sticky navigation bar with official branding and section categories (Men, Women, Kids, Home & Living, Beauty, Studio).
  - Search bar with integrated search icon.
  - User action icons for **Profile**, **Wishlist**, and **Bag** with count badge overlays.
- **Hero Banner Area**:
  - Main promotional hero banners featuring active sales and seasonal campaigns.
- **Category Deals & Brand Display**:
  - Grid layouts featuring top offers, category discounts, and curated collections.
- **Product Cards**:
  - Responsive product card grids with image display, brand titles, item descriptions, pricing, discount percentages, and hover effects.
- **Comprehensive Footer**:
  - Multi-column footer covering customer policies, useful links, original product guarantees, app download links, and social channels.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) for web standards and accessibility.
- **CSS3**: Custom CSS using Flexbox, CSS Grid, positioning, hover states, and CSS custom properties (variables).
- **Icons**: Font Awesome / Boxicons for standard UI icons.
